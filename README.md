Meri PDF Portal 🚀

Meri PDF is a premium, ultra-secure, and 100% client-side PDF utility hub. Built with a "Zero-Knowledge" philosophy, it ensures that your sensitive documents never leave your browser.

✨ Core Features

Merge PDF: Effortlessly combine multiple PDF files into a single, organized document.

Logo Remover: Intelligent cleaning tool to remove watermarks, stamps, and unwanted logos.

Split PDF (Coming Soon): Extract specific pages or ranges with precision.

PDF to JPG (Coming Soon): High-fidelity conversion of document pages into optimized images.

🛡️ Privacy & Security

The standout feature of Meri PDF is its Zero-Knowledge Architecture:

100% Client-Side: All processing happens directly in the user's browser using WebAssembly and JavaScript.

No Uploads: Your files are never sent to a server.

Encrypted Memory: Documents exist only in temporary browser RAM and are purged instantly when the session ends.

No Backend: We have no database, meaning no data harvesting or logs.

🎨 UI/UX Design

The interface is designed for a premium feel while maintaining high readability:

Font: Utilizing Plus Jakarta Sans for a modern, sophisticated aesthetic.

Responsive: Fully optimized for mobile, tablet, and desktop environments.

Visual Feedback: High-contrast tool cards with custom hover states and micro-interactions.

Searchable Toolbox: Instant filtering to find the exact tool you need.

Framework: Tailwind CSS (Modern responsive styling)

Icons: Lucide-React (Crisp, vector-based iconography)

Typography: Google Fonts (Plus Jakarta Sans)

Core Logic: Pure JavaScript with 100% client-side execution.
